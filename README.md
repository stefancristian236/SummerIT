This is the SummerIT summer school final project containing the 1st and 2nd task of the school, alongside the lecturer exemple code.

In order to run the project, besides the node.js and react libraries you also need an account on ***https://www.weatherapi.com/*** where you can get the API key neccesary to acces data.

After acquiring the API key you also need to make a new folder ***/src/.env***;

In .env you need to add the ***PORT=3000*** and also ***KEY= "your api key here"***

In the end run in separate terminals in your file directory ***npm run server*** and ***npm run dev*** in order to activate the backend and frontend.
